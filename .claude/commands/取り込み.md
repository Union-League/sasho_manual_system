# /取り込み — ToDo管理表から①DBへの素起こし転記

## 目的
ToDo管理表の2シートから「マニュアル化=TRUE かつ 取り込み済が空欄」の行を検出し、
①マニュアルDBの最下部に素起こしで転記する。

## 手順

1. 実行者の名前を確認する（最終更新者に記録するため）。

2. ToDo管理表（IDはCLAUDE.md参照）の2シートを読む。
   - シート「現場監視_気づきリスト」: 列 = No. / 内容 / 議論結果 / 起票者 / 起票日 / ステータス / マニュアル化 / ... / 取り込み済
   - シート「Todo」: 列 = No. / 事業区分 / 内容 / ToDo担当者 / 予定(着手/完了) / 実績(着手/完了) / ステータス / メモ / マニュアル化 / ... / 取り込み済
   - **「取り込み済」列がまだ存在しない場合は、各シートの右端に自動追加する**（ヘッダー行に「取り込み済」と書き込む）。
   - 列はヘッダー名で特定すること。列位置のハードコード禁止（列が増減しても壊れないように）。

3. 対象行の抽出: マニュアル化=TRUE かつ 取り込み済が空欄。

4. 各対象行を①DBの行形式へ変換する:
   - ID: DBの現在の最大ID+1から連番
   - 大ジャンル: 13種から内容に最も近いものをClaudeが仮判定（清書時に人が確定する前提）
   - タイトル: 内容から一行要約を生成
   - 内容:
     - 気づきリスト → 「内容」＋「議論結果」を結合した素起こし
     - Todo → 「内容」＋「メモ」を結合した素起こし
     - 整形しすぎない。原文の情報を落とさないことを優先（清書は別工程）
   - 内容種別: テキスト（チェックリスト化の要否は清書時に判断）
   - 転記元: 「気づきリスト No.X YYYY-MM-DD取込」/「Todoシート No.X YYYY-MM-DD取込」
   - 清書完了: FALSE
   - 新人向けフラグ: FALSE（清書時に判断）
   - ステータス: 有効
   - 起票者: 元シートの起票者（Todoシートは ToDo担当者 を代用）
   - 起票日: 元シートの起票日（無ければ空欄）
   - 最終更新者: 実行者名 / 最終更新日: 今日

5. ①DBの最下部に append する（既存行への上書き厳禁）。

6. 転記に成功した行について、ToDo管理表の該当行の「取り込み済」列に今日の日付
   （YYYY-MM-DD）を書き込む。**書き込みは行単位で元の行を再特定して行うこと**
   （読み取り時の行番号を保持し、その行番号に書き込む。処理中に行がずれる操作はしない）。

7. 結果報告: 「気づきリストからX件、TodoシートからY件を取り込みました（DB ID: n〜m）。
   清書をお願いします」の形式でサマリを出す。仮判定した大ジャンルの一覧も表示する。

## 注意
- ToDo管理表への書き込みは「取り込み済」列のみ。他の列・行には一切触れない。
- 同一実行内でDB書き込みに失敗した行には取り込み済マークを付けない（片落ち防止）。
- 対象0件の場合はその旨だけ報告して終了。
